# Cosmik organization profile

`profile/README.md` is the public GitHub organization profile. Cosmik is the parent identity; Tectra and HPLX are its products, not separate organizations or departments.

The profile uses the accepted, unmodified Cosmik lockup from `cosmiklabs/brand` v0.15.1 (`kits/cosmik/assets/vector/cosmik-lockup-offwhite.svg`). The `<picture>` selects the off-white master for dark mode and its accepted ink reverse for light mode. Both SVGs stay unchanged. `profile/assets/cosmik-banner.png` is retained as historical published artwork so existing raw links remain valid.

Product links lead to the organization website’s stable project pages. Do not link private product repositories, promise releases or imply that all Cosmik work has one software license. Identity and copy rules live in the brand kit. The retired motto and historical organization descriptor are not current positioning.
